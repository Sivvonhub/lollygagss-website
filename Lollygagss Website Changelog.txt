Font preload correction (4f04587, 13 pages) — Lighthouse's dependency chain on /services showed two faces arriving 3,000ms+ late (cormorant-garamond-300-italic, playfair-display-900) alongside two more moderately late (jost-300, cormorant-garamond-400-normal). Traced actual above-the-fold usage from the live rendered DOM rather than assumption: jost-300-normal-latin.woff2 (the nav logo's SVG "STUDIO" subtitle) was genuinely above the fold and missing from preload; added it. The other five existing preloads were re-verified live and are all genuine first-paint faces — none removed. The two 3,000ms+ faces are correctly NOT preloaded: cormorant-300-italic only appears in below-the-fold body copy, and playfair-900 is used by .reviews-big-score, which is empty/skeleton in the server-rendered HTML and only populates via JS on window.load, well after first paint.

Font cache headers (75b7ec9, vercel.json) — Both fonts.css and every .woff2 file were shipping Vercel's default Cache-Control: public, max-age=0, must-revalidate — a fresh round-trip to the server on every visit, not just the first. Added a headers rule scoped to /fonts/(.*).woff2 setting public, max-age=31536000, immutable. fonts.css deliberately left on the default policy since its content isn't filename-versioned and could change without a rename.

Font inlining (5f30f19, 13 pages) — fonts.css is 16KB uncompressed for all 45 rules, too much to inline wholesale across 13 pages. Instead inlined just the six @font-face rules for the above-the-fold faces (Jost 300/400/500, Playfair Display 700, Dancing Script 600, Cormorant Garamond 400 italic; latin subset only) directly in each page's <head>, 2,206 bytes of raw CSS per page. fonts.css itself is untouched — still all 45 rules, full unicode-range subsetting intact — and is now loaded via the standard preload-as-style + onload swap so it no longer blocks rendering, with a noscript fallback for JS-disabled clients.
