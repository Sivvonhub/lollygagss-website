## v1.9 — Google Reviews API Integration
**Date: 25 May 2026**

- Added Google Places API integration to display live Google reviews on website
- Three review sections added to index.html (Home, Services, Contact pages)
- Each section displays aggregate star rating, review count, and up to 3 most recent written reviews
- Reviewer name, timestamp ("X months ago" format), and avatar photo included
- Reviews pull from Google Place ID: ChIJHTK4hLlH0i0RMqbSXuaV1XY
- Smart caching: API calls cached for 6 hours to minimise request volume and cost
- Responsive design: reviews grid collapses to single column on mobile
- Language support: review summary labels respect EN/ID language toggle
- Styling integrated into brand palette

**API architecture:**
- Client-side JS fetch calls `/api/reviews` endpoint (no API key exposed in browser)
- Vercel serverless function (`api/reviews.js`) proxies Google Places API
- API key stored securely as environment variable `GOOGLE_PLACES_API_KEY` in Vercel dashboard
- Graceful fallback if API fails or Place ID has no reviews yet

**Setup:**
- Google Cloud Console: Places API enabled, key restricted to Places API + lollygagss.id
- Vercel: `GOOGLE_PLACES_API_KEY` environment variable added to Production environment
- GitHub: `api/reviews.js` added to repo root (auto-deployed by Vercel)
