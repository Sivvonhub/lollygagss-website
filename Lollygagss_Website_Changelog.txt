API Architecture

Cache headers set to 6-hour revalidation with 1-hour stale-while-revalidate window

v1.10 — Bug Fixes: Nav & Google Reviews API
Date: 25 May 2026
Nav links broken (critical fix)

Fixed showPage() conflict introduced in v1.9
Root cause: reviews code redeclared function showPage() using _origShowPage pattern — JavaScript function hoisting caused both declarations to reference each other, breaking all nav link clicks
Fix: removed the override pattern entirely; reviews trigger (loadReviews()) added directly inside the original showPage() function
All nav links (Home, Services, About, Gallery, Journal, Contact) restored

Google Reviews API — fully operational

Rewrote api/reviews.js from CommonJS (module.exports) to ES Module (export default) to match Vercel's runtime expectations
Added "type": "module" to package.json to suppress Vercel's ESM/CommonJS conversion warning
Removed invalid functions runtime block from vercel.json (nodejs18.x is not a valid Vercel runtime string — caused build error)
Switched API call from header-based auth (X-Goog-Api-Key) to query param (?key=) — matches Places API (New) browser behaviour and resolved REQUEST_DENIED errors
Removed timeAgo() function from index.html — Places API (New) returns human-readable relative time strings directly (relativePublishTimeDescription), no calculation needed
Fixed sort function in renderGrid() — removed reference to b.time (classic API field, not present in new API response)
Reviews confirmed live: 5.0 stars, 49 reviews, pulling correctly from Place ID ChIJHTK4hLlH0i0RMqbSXuaV1XY

Debugging notes for future reference

Places API (New) uses places.googleapis.com/v1/places/{ID} not maps.googleapis.com/maps/api/place/details/json
Places API (New) requires billing enabled on Google Cloud project even within free tier
Vercel serverless functions cache aggressively — adding a blank line to force file hash change triggers a true rebuild
HTTP referrer restrictions on Google API keys block server-to-server calls; use no restriction or IP restriction for server-side usage
